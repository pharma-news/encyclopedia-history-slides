# 4500 лет слову — история словарей и энциклопедий

Интерактивная веб-презентация из 15 экранов: от глиняных табличек Шумера до Большой
российской энциклопедии. Собрана на чистом **HTML + CSS**; JavaScript — только
необязательный слой (клавиатура, счётчик, фолбэк-анимации), без него презентация
полностью работает на прокрутке.

**Смотреть:** https://pharma-news.github.io/history/

## Как листать

| Действие | Как |
| --- | --- |
| Вперёд / назад | колесо мыши, свайп, стрелки `↓` `↑`, `PgDn` `PgUp`, пробел |
| Первый / последний экран | `Home` / `End` |
| Перейти к главе | точки справа, меню сверху |
| Режим показа | клавиша `F` (или `а` в русской раскладке) |
| Сохранить в PDF | `Ctrl + P` — у презентации отдельная печатная вёрстка |

## Дизайн и техника

- **Палитра следует за эпохой**: глина → золото Рима → киноварь Китая → слоновая
  кость Просвещения → сталь XIX века → советский красный → синий БСЭ → цифровой
  градиент БРЭ. Акцент подмешивается в фон, свечение, цифры и рамки.
- **У каждого экрана — свой артефакт**. Слайд разделён на два столбца: слева текст,
  справа «витрина» — рамка с настоящей фотографией артефакта, подписью и цифрами.
  Фотографии лежат в папке `Slide/` и названы по номеру слайда: `Слайд1.JPG` —
  шумерские таблички, `Слайд2.JPG` — Плиний, … `Слайд13.JPG` — тома БРЭ.
  Рамка слегка обрезает чёрные поля коллажей, подкрашивает их акцентом эпохи и
  мягко приближается при наведении.
- Часть иллюстраций осталась CSS-графикой: этимология ἐγκύκλιος, счётчик 71 818
  статей Дидро, гонка гуся и ржанки, словарная статья Даля, 82 полутома Брокгауза,
  мост «36 томов → экран» и финальная хронология.
- Иллюстрации — **инлайновый SVG и локальные JPG** (без внешних запросов), данные —
  CSS-градиенты, поэтому презентация работает офлайн.
- **Масштаб без «слайдовой ломки»**: все размеры заданы единицей
  `--s: min(1vw, 1.66vh)`, поэтому экран всегда целиком помещается во вьюпорте —
  и на проекторе 1024×768, и на 4K. На телефоне дек превращается в вертикальную ленту.
- Появление блоков сделано на **scroll-driven animations**
  (`animation-timeline: view()`), с фолбэком на `IntersectionObserver`.
- Поддержаны `prefers-reduced-motion`, `:focus-visible`, семантические разделы и
  `aria`-метки для декоративных элементов; есть печатная версия `@media print`.
- Шрифты: Unbounded (дисплейный), Manrope (текст), Playfair Display (цитаты),
  IBM Plex Mono (подписи и метки эпох).

## Структура

```
index.html      слайды и текст
assets/styles.css   сетка, типографика, компоненты, навигация, печать
assets/slides.css   палитры эпох и CSS-иллюстрации
assets/deck.js      необязательный прогрессивный слой (~140 строк)
assets/favicon.svg  глиняная табличка
Slide/              фотографии артефактов: Слайд1 … Слайд13 (по номеру экрана)
```

## Локальный запуск

```bash
git clone https://github.com/pharma-news/encyclopedia-history-slides
cd encyclopedia-history-slides
python -m http.server 8000
# затем открыть http://localhost:8000
```

Можно и без сервера: просто открыть `index.html` в браузере.
